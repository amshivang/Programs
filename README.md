# 📚 Programs & Academic Coursework

Welcome to the **Programs** repository!

This repository contains academic syllabus assignments, algorithm implementations, and problem-solving exercises in **C**, **C++**, **Data Structures & Algorithms (DSA)**, **Java**, and **Python**.

## 🛠️ Usage & Compilation

* **C Programs**: `gcc program.c -o program`
* **C++ Programs**: `g++ program.cpp -o program`
* **Java Programs**: `javac Program.java` then `java Program`
* **Python Programs**: `python program.py`
