## 📌 Overview

This repository serves as the official academic code compendium and algorithm laboratory for **Shivang Shukla** in the **Computer Science & Engineering (Cybersecurity)** curriculum.

It catalogues foundational programming constructs, memory management with low-level pointers, Object-Oriented software architectures, asymptotic complexity analyses, and practical Data Structures & Algorithms across four primary languages: **C**, **C++**, **Java**, and **Python**.

## 🛠️ Compilation & Execution Guide

### 1. C Programs
Compile using GCC with standard C11 flags:
```bash
gcc -std=c11 "C Programs/factorial.c" -o factorial
./factorial
```

### 2. C++ Programs & DSA
Compile using G++ with modern C++ standards:
```bash
g++ -std=c++17 "C++ Programs/complex_numbers.cpp" -o complex
./complex
```

### 3. Java Programs
Compile and execute using modern JDK tooling:
```bash
javac "Java Programs/Quadratic.java"
java -cp "Java Programs" Quadratic
```

### 4. Python Programs
Execute directly using Python 3 runtime:
```bash
python "Python Programs/armstrong.py"
```
